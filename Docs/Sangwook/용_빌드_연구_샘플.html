용 빌드의 3층 구조

① 성장 (Growth)

슬라임과 특화자원을 먹여 레벨을 올리고 진화시킵니다. 성장하면 성장 포인트(SP)와 스킬트리 티어가 열립니다.

→ "얼마나 자원을 용에 투자할 것인가" (인구·생산과 경쟁)

② 스킬트리 (Build)

획득한 SP를 속성별 스킬트리에 투자합니다. 공통·특화·시너지 3분기 + 각성 궁극기로 나만의 빌드를 완성합니다.

→ "이 용을 어떤 역할로 키울 것인가" (제어/폭딜/유틸/방어/유지)

③ 시너지 (Synergy)

용의 속성이 같은 속성 타워·지역과 만나면 강력한 보너스가 발동. 새끼용과의 합동 스킬도 존재합니다.

→ "용을 중심으로 방어 전체를 어떻게 엮을 것인가"

4X 설계 원리 (기존 연구 트리와 공유)

eXplore · 탐험
숨김 노드 — 특정 속성·조합을 달성해야 열리는 비밀 스킬 (예: 속성 교배, 용의 계약)
eXpand · 확장
SP·연구 포인트를 투자해 단계적으로 능력을 개방하는 기본 성장 축
eXploit · 착취
배타 선택 — 전투형/버프형, 극단 특화 등 한 방향으로 몰아주는 선택
eXterminate · 섬멸
각성(궁극기) — 한 속성을 끝까지 판 플레이어에게 주는 전맵 규모 보상
🥚
용 성장 · 진화 시스템
먹이 소모 → 레벨링 → 진화 → 스킬포인트 획득
용은 먹이(슬라임)로 경험치를 얻어 레벨을 올리고, 특화자원을 소모해 진화합니다. 레벨업은 성장 포인트(SP)를, 진화는 스킬트리 티어를 개방합니다. 자원을 용에 쓸지 인구·타워에 쓸지가 낮의 핵심 선택이 됩니다.

성장 재화 3종

🟢 슬라임 (먹이)

외곽·중앙에서 획득하는 용의 기본 먹이. 소모 시 용 경험치가 오르고 레벨이 상승합니다.

→ 레벨 = SP(성장 포인트)의 원천

🟣 특화자원 (진화 재료)

4개 바이옴별 고유 자원. 각 속성 용의 진화 조건 재료이자 속성 각성의 열쇠입니다.

→ 진화 = 스킬트리 상위 티어 개방

⭐ 성장 포인트 (SP)

레벨업·진화·보스 처치로 획득하는 스킬트리 투자 화폐. 초기화(리스펙)는 슬라임을 소량 소모해 가능합니다.

→ 스킬트리 노드 연구에 사용

진화 4단계 (어미용)

단계진화 조건개방 내용비고
💡 진화 게이트 설계 의도 — 각 진화는 "레벨(슬라임)" + "특화자원(원정으로 점령한 바이옴)"을 동시에 요구합니다. 즉 용을 키우려면 반드시 확장(점령)을 해야 하고, 확장하면 적 난이도가 오르므로 "리스크 → 리워드" 구조가 성장에도 그대로 적용됩니다.

어미용 5속성 스킬트리
공통 성장 + 속성 특화 + 시너지 + 각성 궁극기
모든 어미용은 공통 성장 분기(어느 속성이든 동일)와 속성 특화 분기, 지역·시너지 분기를 가지며, 특화 분기 끝에는 진화 4단계에서만 열리는 각성(궁극기)가 있습니다. 아래에서 속성을 선택해 상세 트리를 확인하세요.
공통 성장 (모든 속성 공유) 속성 특화 지역·시너지 각성 (궁극기) 숨김 노드
🧩 공통 성장 분기는 5속성 모두 동일합니다: 용의 위엄(공격력 +12%/Lv, 3Lv) → 용린(생명력·방어 +15%/Lv, 3Lv) → 비룡(액티브 스킬 쿨다운 -8%/Lv, 3Lv). 위 트리에는 각 속성의 특화·시너지·각성 분기만 표시합니다.
🐣
새끼용 빌드
전투형 / 버프형 배타 선택 · 속성별 필드 효과 · 군단 시스템
새끼용은 어미용과 같은 5속성으로 존재하며, 부화 시 전투형(독립 전투) 또는 버프형(지원) 중 하나를 배타 선택합니다. 어미용이 "판 전체를 지배하는 축"이라면, 새끼용은 "특정 경로·구역을 책임지는 유닛"입니다.

⚔ 전투형 (Combat)

배치한 경로를 순찰하며 독립 전투. 속성 공격으로 적을 직접 처치하고, 어미용 스킬의 표식/상태이상을 함께 굴립니다.

연구 트리 확장안
기존 4카테고리에 추가 제안하는 18개 노드
기존 연구 프로토타입(용 · 타워 · 생산 · 편의 4카테고리)에 용 성장 루프를 뒷받침할 추가 노드를 제안합니다. 특히 용 카테고리에 성장·먹이 효율 분기를 신설해, 연구 트리와 용 스킬트리가 서로를 강화하도록 연결했습니다. NEW = 신규 제안.
🔮 숨김 노드 연계 — 기존 용의 계약(어미·새끼 마스터리 동시 달성)에 더해, 신규 속성 교배(서로 다른 두 속성 용 각성 시 → 혼합 속성 스킬 해금)를 제안합니다. 이는 4X의 eXplore 축을 강화하고, 리플레이 동기를 만듭니다.

빌드 아키타입 & 시너지
속성별 추천 빌드 · 타워 연계 · 포인트 예산
용 스킬트리 + 타워 + 인구 배분을 하나로 묶은 6개 대표 빌드를 제안합니다. 플레이어가 초반에 어떤 바이옴을 점령하느냐(=어떤 특화자원/속성을 확보하느냐)에 따라 자연스럽게 아키타입이 갈립니다.

포인트 예산 (예시 밸런스)

주기낮/밤 수누적 연구 포인트누적 용 SP권장 지출 방향
⚖ 밸런스 원칙 — 한 주기의 SP로는 한 속성의 특화 분기 하나를 겨우 완성할 정도로 책정. 각성(궁극기)은 주기 2 보스 이후에야 도달 가능하게 하여, "끝까지 판 보상"의 무게를 유지합니다. 리스펙 비용(슬라임)은 존재하되 저렴하게 두어 실험을 장려합니다.
