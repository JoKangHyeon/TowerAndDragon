## 1. 결론 요약

이슈 #111의 핵심 런타임 흐름은 현재 작업 씬에서 연결되어 있습니다.

- 전체 4주기, 주기당 7웨이브로 총 28일을 진행합니다.
- 7·14·21·28일차는 각 주기의 보스 웨이브입니다.
- 포탈은 North → South → East → West 순서로 누적 활성화됩니다.
- `DailyWaveController`는 기존 `WaveScheduleSO`가 아니라 `WaveCycleProgression`의 현재 스냅샷에서 웨이브를 가져옵니다.
- `WaveCycleSchedule_Main.asset`은 `wave_1`부터 `wave_28_Boss`까지 각 일차의 독립 에셋을 참조합니다.
- 사용자 플레이 테스트에서 1~28일차 웨이브와 주기별 포탈 스폰이 정상 동작하는 것을 확인했습니다.
- Unity 컴파일 오류와 현재 Console 오류는 없습니다.

아직 남은 필수 정리 작업은 다음 두 가지입니다.

1. EditMode 테스트 20개를 현재 변경 기준으로 재실행합니다.
2. 신규 검증 씬과 `DailyWaveController` 변경을 검토한 뒤 커밋합니다.

28일차 이후 승리 처리, 포탈 연출, 저장·불러오기와 실제 빌드 씬 반영은 별도 후속 범위입니다.

`기획종합_v2.md`에는 주기당 일수가 `[미정]`으로 남아 있지만, 이슈 #111 구현은 사용자 확인에 따라 **주기당 7웨이브**를 적용합니다. 기획 원본 수정은 기획 담당자의 영역이므로 이번 작업에 포함하지 않습니다.

### 2.2 구현 규칙

1. 전체 게임 주기는 4주기입니다.
2. 한 주기는 7개의 밤 웨이브로 구성됩니다.
3. 각 주기의 7번째 웨이브는 보스 웨이브입니다.
4. 포탈 해금 순서는 North → South → East → West입니다.
5. 새 주기가 시작되면 다음 포탈이 누적 활성화됩니다.
6. 포탈 개방은 현재 `Portal.IsActive`를 통한 스폰 활성화를 의미합니다.
7. 포탈 봉인 해제 애니메이션, VFX, 사운드와 안내 UI는 후속 작업입니다.
8. 최종 승리 처리는 연결하지 않고 `AllCyclesCompleted` 이벤트만 제공합니다.

## 4. 현재 런타임 흐름

다음 흐름이 `Assets/Scenes/Sangwook_WaveCycleSchedule.unity`에 연결되어 있습니다.

```text
CycleManager.OnDayStart(currentDay)
  → WaveCycleProgression
  → WaveCycleScheduleSO.TryResolve(currentDay)
  → WaveCycleSnapshot 갱신
  → 새 주기이면 PortalProgressionController.ApplyCycle(cycleNumber)
  → Portal.SetSpawnActive(...)

CycleManager.OnNightStart(currentDay)
  → DailyWaveController
  → 현재 스냅샷의 TotalDay 검증
  → WaveCycleProgression.TryGetCurrentWaveDefinition(...)
  → WaveManager.StartWaveAsync(waveDefinition)
  → 활성 포탈별 적 생성
  → 모든 적 전멸
  → WaveManager.AllMonstersDefeated
  → CycleManager.EndNight()
  → 다음 낮 시작
```

보스 웨이브의 밤이 끝나면 `WaveCycleProgression.CycleCompleted`가 발생합니다. 4주기 보스 종료 시 `AllCyclesCompleted`도 발생하지만 현재 소비자는 없습니다.

### 8.2 최종 승리 처리

`WaveCycleProgression.AllCyclesCompleted` 이벤트는 존재하지만 소비자가 없습니다. 현재 `CycleManager.EndNight()`는 다음 낮을 시작하므로, 28일차 종료 후 계속 진행하면 29일차 일정 조회가 실패합니다.

28일차 이후 진행 차단, 승리 화면, 결과 정산과 세이브 처리는 별도 후속 이슈로 구현합니다.

### 8.3 포탈 연출

- 봉인 해제 애니메이션
- 포탈 VFX와 사운드
- 새 포탈 개방 안내 UI

현재는 `Portal.SetSpawnActive()` 상태 변화가 후속 연출의 연결점입니다.

### 8.4 UI 규칙 통합

`UI_IngameWindow`는 7일 표시를 자체 상수와 계산으로 표현합니다. 현재 결과는 맞지만 `WaveCycleRules.WAVES_PER_CYCLE` 또는 `WaveCycleSnapshot`을 사용하지 않아 규칙이 중복되어 있습니다.

### 8.5 저장·불러오기와 씬 재진입

`PortalProgressionController.ApplyCycle()`은 누적 상태를 다시 계산할 수 있지만 저장된 일차를 불러오거나 씬에 재진입했을 때 상태가 복구되는지는 아직 검증하지 않았습니다.
