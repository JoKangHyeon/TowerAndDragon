## 1. 적 / 웨이브

- 이번 빌드에서 추가된 모든 적 정상 작동

        - 높은 체력 및 낮은 이동속도 확인
    - 용사냥꾼형
        - 용 타워 타겟팅 확인
    - 보호형 
        - 주위 몬스터 보호막 부여 확인.

## 2. 타워 & 새끼용 (공격 및 버프 모드)

- 속성별 타워 정상 작동 확인 
    - 얼음 : 둔화
    - 불 : 화상 (지속 데미지)
    - 대지 : 광역 높은 데미지
    - 시간 : 주위 타워 공격 속도 증가
- 인구 충원율에 따라 재활성화 시간 연동 확인
    - 인구 배치를 하지 않은 타워는 재활성화 X
- 지형별 배치 페널티 정상 작동 확인
    - 사막 
    - 용암 
    - 암석
    - 얼음
- 각 새끼용으로 페널티 극복 확인
- 새끼용 버프 / 공격 모드 전환 및 효과 확인
    - 버프 모드 효과 제대로 적용 확인
    - 공격 모드 공격 효과 작동 확인
        - 각종 이펙트 효과 확인
