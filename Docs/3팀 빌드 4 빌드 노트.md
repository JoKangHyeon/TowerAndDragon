# 플레이 가이드

### 단축키

| 키 | 기능 |
|---|---|
| `B` | 건설 모드 (배치·철거·이동) |
| `V` | 인구 배치 모드 (건물 클릭으로 인구 배치/회수, Shift=최대, Ctrl=5명 단위) |
| `C` | 점령 모드 (인접 지역 선택 → 원정) |
| `Tab` | 새끼용 인벤토리 |
| `Space` | 밤 전투 일시정지 |
| `R` | 건물 회전 (건설 모드 중) |
| `WASD` / 방향키 | 카메라 이동 |
| 마우스 휠 | 확대 · 축소 |
| 좌클릭 | 선택 · 배치 · 확정 |
| `Esc` | 모드 종료 / 창 닫기 |

### 타워 정보

| 타워 | 속성 | 역할 |
|---|---|---|
| 화살탑 / 석궁탑 / 총탑 | 무속성 | 기본 단일 대상 공격탑 (사거리·공격력 순으로 강화, 필요 인구도 증가) |
| 얼음 타워 | 얼음 | 공격 시 적 이동속도 감소 |
| 화염 타워 | 불 | 공격 시 화상(지속 피해) 부여 |
| 암석 타워 | 암석 | 광역 공격 |
| 시간 타워 | 시간 | 직접 공격은 없고, 주변 아군 타워의 공격속도·재활성화 속도를 올리는 오라형 |
| 생명 타워 | 생명 | 개발 예정 (미구현) |

- 타워는 인구를 배치해야 작동하며, 인구가 부족하면 비활성화됩니다.
- 지형에 따라 배치 페널티가 붙을 수 있습니다.

### 새끼용(베이비 드래곤) 속성별 정보

새끼용은 **공격 모드 / 버프 모드**를 전환해 사용합니다. 버프 모드는 먹이를 먹여 가동 중일 때만 주변 생산시설의 생산량을 올려줍니다.

| 속성 | 공격 모드 | 버프 모드 |
|---|---|---|
| 얼음 | 둔화 부여, 스택 시 일시 빙결 | 인근 생산량 소폭 증가 |
| 불 | 화상 부여, 화상 중 추가 피해 | 인근 생산량 소폭 증가 |
| 시간 | 피해는 낮지만 매우 빠른 공격속도 | 인근 생산량 소폭 증가 |
| 암석 | 광역 공격, 피격 대상 이동속도 대폭 감소 | 돌·특화 자원 생산량 크게 증가 |
| 생명 | 공격할 때마다 주변 아군 타워 체력 회복 | 식량·통나무 생산량 크게 증가 |

### 어미용 속성 (참고)

얼음 · 불 · 시간 · 암석 · 생명 5속성 중 하나를 **낮에 한 번** 선택/변경할 수 있고, 속성마다 낮 시간 맵 패시브 효과와 밤에 쓰는 액티브 스킬이 다릅니다. 자세한 수치는 `Docs/기획종합_v2.md` 참고.

### 몬스터 종류

| 유형 | 특징 |
|---|---|
| 기본형 (지상/공중) | 표준 체력·이동속도의 근접 공격 (공중형은 이속이 빠른 대신 체력이 낮음) |
| 공격형 | 이동 중에도 타워를 우선 공격 |
| 탱커형 | 체력이 매우 높은 대신 이동속도가 느림 |
| 원거리형 (지상/공중) | 사거리를 두고 투사체로 공격 |
| 용사냥꾼형 | 지상 유닛이지만 이동 중 하늘의 용만 노림 |
| 보호형 | 주변 아군 몬스터에게 방어막 부여 (범위 이탈 시 회수) |
| 마비형 | 타워·용에게 마비 상태이상 부여 |
| 자폭형 | 사거리 내 타워 발견 시 점화 후 폭발(광역 피해), 자신도 사망 |
| 속성 면역형 / 속성 전용형 | 얼음·불·암석·생명 속성별로 존재. 해당 속성 공격만 차단하거나, 반대로 해당 속성 공격만 통함 |

- **보스** (7·14·21·28일차 등장, 일반 몬스터와 함께 스폰): 체력 800 → 1600 → 2400 → 4000으로 주기마다 증가, 이동속도는 매우 느리며 타워·용을 모두 공격.
- 속성 간 상성(유불리)은 없고, 면역/전용 판정은 "해당 속성만 통과/차단"의 이진 규칙입니다.

## 1. 적 / 웨이브

- **특수형 몬스터 추가** — 탱커형, 용사냥꾼형, 보호형(아군 보호 오라) 구현 및 테스트 완료
- **속성형 / 속성 면역형 적 추가** — 타워·용 속성과 상성으로 연결
- **웨이브 개편** — 웨이브 생성 방식 변경, 웨이브 데이터 정비, 다음 웨이브 적 예고 표시기 개선

## 2. 타워

- **속성 타워 구현 완료** — 속성별 공격 특성 적용
- **시간 타워 오라(버프)** 적용 및 버프 타워 사정거리 표시 연결
- **타워 재활성화 시간** 조정, 인구 충원율에 따라 재가동되도록 연동
- **지형별 배치 패널티** 추가

## 3. 용 (어미용 / 새끼용)

- **새끼용 보상 연결** — 주기 보스 처치 시 랜덤 속성의 알 획득
- **생명 속성 새끼용** 버프 구현 및 수치 조정
- **새끼용 공격 모드** 구현 완료 (버프 모드에서도 공격하던 문제 수정)
- **어미용 속성 기능** 및 속성 변경 제한 경고 추가
- **용 관리 UI 전면 개편**
  - 새끼용 창을 별도 창에서 통합 UI로 이관 (구 babyDragonWindow / 버튼 제거)
  - 새끼용 UI 레이아웃·디자인 정리, 용 관련 연출 추가
  - 스킬 사용 시 다른 창이 자동으로 닫히도록 개선

## 4. 인구 / 자원 / 점령

- **인구 배치 모드** 추가
- **인구 감소 표시** — 식량 부족 시 예상 감소량 표기, 연구소 배치 인원 기아 감소 반영
- **자원 표시 개선** — 건물 자원 소모량 표시, 툴팁 추가
- **슬라임** — 슬라임 농장에 슬라임 표시, 생산량에 따른 자원량 표기 UI 정리
- **점령 표시 개선** — 점령지 / 점령 불가 하이라이트 방식 변경, 자투리 점령지 처리, 맵 외곽선에 맞춘 경계선, 점령 모드 표시선 연결
