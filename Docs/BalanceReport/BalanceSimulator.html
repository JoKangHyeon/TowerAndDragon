게임 코드에서 그대로 가져온 규칙

  • 타워 발사 간격 = Interval / 충원율 / 공속배율 (TowerAttack.cs:187)
  • 몬스터는 사거리 안에 타워가 들어오면 멈춰서 때린다 (MonsterAttack.SetCurrentTarget)
  • 타워는 단일 대상을 잡고 죽거나 벗어날 때까지 유지 — 광역 타워만 예외
  • 성에 도달한 몬스터는 성을 직접 때린다 (BaseMonster.HandleArrivedAtCastle)
  • 폭탄병 폭발은 타워만 맞는다. 성은 IMonsterTarget이 아니라 안 맞는다
  • 보호막 오라는 대상당 1회만 부여(_grantedOnce), 범위 이탈 시 회수
  • 점령 페널티는 점령한 청크의 지형이 배정된 포탈에만 적용
  • 속성 규칙(Only/Immune/AllImmune)이 실제로 피해를 차단한다

모델의 한계 — 결과를 이만큼 의심할 것

  • 경로 길이·방어선 깊이는 추정값이다. 실제 맵 스플라인을 쓰지 않았다. 출고값 기준 7일차 사망(플레이 테스트 관측 7~10일차)에 맞춰 보정했고, 경로 길이 16~45 전 구간에서 같은 판정이 나온다.
  • 타워를 어디에 놓는지는 모델링하지 않는다. "포탈 접근로에 고르게 편다"로 추상화했다.
  • 한 포탈의 루트 2개는 성 앞에서 합류한다고 본다. 타겟 경합은 유지된다.
  • 인구 배분은 정책 슬라이더가 자동으로 굴린다. 실제 플레이어의 판단은 더 좋을 수도 나쁠 수도 있다.
  • 기아 페널티, 새끼용, 랜드마크, 봉인석, 지형 유지비는 아직 안 들어갔다.
