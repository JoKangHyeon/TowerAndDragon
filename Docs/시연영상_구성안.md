# 수성록 (Tower and Dragons) — 시연 영상 구성안

> 대상: 최종 결과 보고 제출용 시연 영상
> 제출 요건: **5~10분 / 100MB 이하 / 기능별 소개 음성 포함 / 별도 파일 제출 가능**
> 기준 빌드: 빌드 6 (베타 준비) 이후 · `SampleScene` / `Tutorial`
> 작성일: 2026-08-27

---

## 0. 총평 — 이 영상이 증명해야 하는 것

심사자가 이 영상에서 확인하려는 것은 "예쁜가"가 아니라 **"기획한 시스템이 실제로 서로 물려서 돌아가는가"** 입니다.
따라서 기능을 나열하는 카탈로그식 구성이 아니라, **하루(낮 → 밤 → 정산)를 한 번 완주하는 흐름을 먼저 보여주고,
그 위에 성장 축(점령·연구·용)을 얹는 순서**를 권장합니다.

핵심 메시지 3줄 (내레이션 전체를 이 세 문장에 수렴시킬 것):

1. 낮에 한정된 인구를 어디에 넣느냐가 그날 밤의 결과를 결정한다.
2. 점령하면 강해지지만 동시에 적도 많아진다 — 확장 자체가 리스크다.
3. 용은 연구와 분리된 두 번째 성장 축으로, 판을 뒤집는 개입 수단이다.

## 2. 컷별 상세 촬영 지시

### 00 · 타이틀 · 오프닝 (0:00 ~ 0:20)

| 항목 | 내용 |
|---|---|
| 화면 | 시작 씬 타이틀 → "게임 시작" 클릭 → 맵 페이드인 |
| 촬영 팁 | 시작 씬 설정창을 살짝 열었다 닫아 해상도·사운드 옵션이 있음을 스치듯 노출 |
| 내레이션 | "타워디펜스와 도시건설을 결합한 싱글플레이 전략 게임, 수성록입니다. 한 줄 컨셉은 '낮의 선택이 밤의 생존을 결정한다'입니다." |

### 01 · 게임 개요 · 맵 전경 (0:20 ~ 1:00)

| 항목 | 내용 |
|---|---|
| 화면 | 카메라를 줌아웃해 맵 전체 → 중앙 메인 성 → 동서남북 포탈 순서로 천천히 팬 |
| 반드시 담을 것 | ① 중앙 초원 + 외곽 4바이옴(용암·사막·설원·암석) ② 포탈 위치 ③ 전장의 안개 ④ 상단 HUD(일차·자원·인구) |
| 촬영 팁 | 미니맵을 한 번 클릭해 미니맵 존재를 보여줄 것 (레터박스 제거 완료) |
| 내레이션 | "맵 중앙에 지켜야 할 메인 성이, 동서남북에 적이 넘어오는 포탈이 있습니다. 28일 4주기 동안 포탈이 하나씩 늘어납니다. 승리 조건은 두 가지 — 최종 보스 격파, 또는 네 포탈 모두에 봉인석 건설입니다." |

### 02 · 낮 — 건설과 인구 배치 (1:00 ~ 2:15) ★ 가장 중요

| 항목 | 내용 |
|---|---|
| 화면 순서 | ① `B` 건설 모드 → 공격로 옆에 화살 타워 2개 배치 (`R` 회전 한 번 보여주기) ② 초록색 자원 지역에 농장·벌목장 배치 ③ `V` 인구 배치 모드 → 타워에 인구 투입 → **남은 인구가 줄어드는 HUD를 명확히 보여줄 것** ④ 생산시설에도 인구 배치 ⑤ 자원 UI 호버 → 다음 날 예상 증감 툴팁 노출 |
| 반드시 담을 것 | **"인구를 타워에 넣으면 생산에서 빠진다"가 화면상 수치로 드러나는 순간.** 이 컷 하나가 게임의 핵심입니다. |
| 촬영 팁 | 인구 배치·회수 시 주민 캐릭터가 성과 건물 사이를 실제로 이동하는 연출을 꼭 프레임에 담을 것 (빌드 6 신규) |
| 내레이션 | "낮에는 시간 제한이 없습니다. 타워를 짓고, 생산시설을 짓고, 인구를 배분합니다. 인구는 하나의 풀을 생산·방어·점령·연구가 공유하기 때문에, 타워에 넣은 인구만큼 생산이 줄어듭니다. 여기서 매일 트레이드오프가 발생합니다." |

### 03 · 밤 — 웨이브 방어 (2:15 ~ 3:20) ★ 가장 중요

| 항목 | 내용 |
|---|---|
| 화면 순서 | ① "밤으로 변경" 클릭 → 낮/밤 전환 연출 ② 포탈에서 웨이브 진입 ③ 타워 발사·명중 이펙트 ④ **적 호버 툴팁**을 한 번 띄워 체력·이동방식·속성 규칙 노출 ⑤ 타워 하나가 파괴 대신 **비활성화**되는 장면 ⑥ 전멸 → 승리 |
| 반드시 담을 것 | 타워 **비활성화** 순간. 이 프로젝트의 대표 설계 결정이므로 클로즈업 + 내레이션으로 반드시 짚을 것 |
| 촬영 팁 | 전투가 지루하면 2배속을 쓰되, **비활성화 순간과 첫 교전만은 1배속**으로. 배속 UI가 화면에 보이므로 "배속 지원"도 자연히 어필됨 |
| 내레이션 | "밤에는 개입 여지가 적습니다. 낮에 준비한 그대로 결과가 나옵니다. 주목할 점은 타워가 파괴되지 않고 비활성화된다는 것입니다. 다음 날 인구를 다시 채우면, 그 충원율에 비례해 부활 시간과 공격 속도가 결정됩니다. 밤의 실패가 게임 오버가 아니라 다시 인구 배분 문제로 되돌아오게 만든 설계입니다." |

### 04 · 정산 — 자원 순환 (3:20 ~ 3:50)

| 항목 | 내용 |
|---|---|
| 화면 | 밤 종료 → 정산 → 자원 증가 표시 → **식량이 인구 유지비로 빠지는 것** → 비활성 타워에 인구 재충원 |
| 반드시 담을 것 | 식량 유지비 차감. "인구를 늘리는 것 자체에 비용이 든다"를 증명하는 장면 |
| 내레이션 | "밤이 끝나면 전날 배치한 시설에서 자원이 한꺼번에 들어옵니다. 동시에 인구 수만큼 식량이 유지비로 빠집니다. 인구는 공짜로 좋은 자원이 아니라, 늘릴수록 비용이 붙는 자원입니다." |

### 05 · 점령 — 영토 확장과 리스크 (3:50 ~ 4:50)

| 항목 | 내용 |
|---|---|
| 화면 순서 | ① `C` 점령 모드 → 점령 가능 영역 외곽선 하이라이트 ② 인접 청크 선택 → 인구·재료 소모 후 원정 출격 ③ 병사 캐릭터가 청크로 이동·집결하는 연출 ④ (며칠 뒤 세이브) 점령 완료 → 영토 확장, 인구·자원 획득 ⑤ 지형 페널티가 걸린 청크 정보창 노출 |
| 반드시 담을 것 | 점령 후 **다음 밤 웨이브의 적 수가 눈에 띄게 늘어난 장면**. 리스크-리턴이 말이 아니라 화면으로 증명됨 |
| 촬영 팁 | 점령 전/후 웨이브를 나란히 편집(스플릿 또는 컷 대비)하면 설득력이 크게 올라감 |
| 내레이션 | "점령하면 인구와 특화 자원, 신규 타워를 얻습니다. 다만 점령할수록 적의 스폰 수가 늘어납니다. 초기에는 적 스탯을 배율로 올렸는데, 곱연산이 겹쳐 난이도가 비선형으로 폭발해서, 추가 스폰 중심으로 바꿨습니다." |

### 06 · 연구 — 장기 투자 축 (4:50 ~ 5:20)

| 항목 | 내용 |
|---|---|
| 화면 | 연구소에 인구 배치 → 정산 시 RP 획득 → 연구 창 열기 → 3갈래 트리 전경 → **실제 효과가 붙어 있는 노드**를 하나 찍기 |
| ⚠️ 주의 | 현재 25노드 중 **10개는 효과가 비어 있음.** 아래 "촬영 금지 목록" 참조 — 반드시 효과가 연결된 15개 중에서 고를 것 |
| 내레이션 | "연구소에 인구를 배치하면 연구 포인트가 쌓입니다. 타워·생산시설·편의 세 갈래로 나뉘며, 즉시 효과가 없다는 점 자체가 이 시스템의 기회비용입니다." |

### 07 · 용 ① 어미용 (5:20 ~ 6:10) ★ 차별화 포인트

| 항목 | 내용 |
|---|---|
| 화면 순서 | ① 메인 성의 어미용 클릭 → 속성 변경 창 → 얼음 → 불로 변경 (맵 전역 패시브 설명 텍스트 노출) ② 용 스킬트리 창 열기 → 5속성 탭 전환하며 트리 전경 스크롤 ③ 밤으로 진입 → 적이 몰린 타이밍에 **액티브 궁극기 발동** |
| 반드시 담을 것 | 궁극기 연출. 영상 전체에서 가장 "임팩트 있는 그림"이므로 적이 가장 많이 몰린 순간에 쓸 것 |
| 촬영 팁 | 궁극기는 1배속 + 필요하면 편집에서 0.5배 슬로우. 스킬트리는 빠르게 스크롤해 "규모"만 전달 (노드 하나하나 읽히게 하지 말 것) |
| 내레이션 | "용은 연구와 완전히 분리된 두 번째 성장 축입니다. 어미용은 다섯 속성 중 하나를 낮에 한 번 바꿀 수 있고, 속성마다 맵 전역 패시브와 액티브 궁극기를 가집니다. 속성별 여덟 슬롯, 총 일흔 개 노드의 전용 스킬트리로 성장합니다." |

### 08 · 용 ② 새끼용 (6:10 ~ 6:45)

| 항목 | 내용 |
|---|---|
| 화면 | `Tab` 새끼용 인벤토리 → 부화한 새끼용을 필드에 배치 → 공격/버프 모드 전환 → HUD의 **슬라임 잔량 요약(▲▼!)** 호버 |
| 반드시 담을 것 | 새끼용이 인구가 아니라 **슬라임을 먹는다**는 점. HUD 슬라임 툴팁이 이를 한 화면에 보여줌 |
| 내레이션 | "새끼용은 주기 보스를 잡으면 알로 얻어 부화시킵니다. 인구가 아니라 슬라임을 먹고 가동되며, 공격 모드와 버프 모드 중 선택합니다. 버프 모드는 생산 배율, 건설 제한 해제, 지형 페널티 무효화 같은 지역 한계를 풀어줍니다." |

### 09 · 보스 웨이브 (6:45 ~ 7:25)

| 항목 | 내용 |
|---|---|
| 화면 | 보스 등장 예고 → 보스 진입 → 타워·용 총력 대응 → 격파 → **용알 보상 획득** |
| 촬영 팁 | 7일차 보스보다 **21일차 또는 28일차 최종 보스**가 그림이 훨씬 좋음 (타워 다수 + 속성 타워 + 용 궁극기 동시 노출) |
| 내레이션 | "7일마다 주기 보스가, 28일차에 최종 보스가 등장합니다. 보스는 타워와 용을 모두 공격 대상으로 삼기 때문에, 배치 위치 자체가 판단 대상이 됩니다." |

### 10 · 승리 · 온보딩 · 클로징 (7:25 ~ 8:00)

| 항목 | 내용 |
|---|---|
| 화면 순서 | ① 승리 화면 ② (빠르게) 튜토리얼 씬 챕터 안내 오버레이 1컷 ③ 가이드 퀘스트 팝업 1컷 ④ 도움말 도감 1컷 ⑤ 설정창·키 리바인딩 1컷 ⑥ 팀 크레딧 |
| 촬영 팁 | ②~⑤는 각 3~4초의 빠른 컷 몽타주로. 개별 설명 없이 "신규 플레이어 대응도 갖췄다"만 전달 |
| 내레이션 | "처음 플레이하는 사람을 위해 전용 튜토리얼 씬과 본게임 가이드 퀘스트 스물일곱 종, 도움말 도감 아홉 종을 준비했습니다. 이상으로 수성록 시연을 마칩니다. 감사합니다." |

## 3. ⚠️ 촬영 금지 · 회피 목록

빌드 6 결과 보고서 기준 **미완료 또는 오동작 구간**입니다. 화면에 잡히면 감점 요인이 되므로 의도적으로 피합니다.

| 항목 | 상태 | 회피 방법 |
|---|---|---|
| 대공 타워 세이브 | `PrefabId`가 `TP_Musket`으로 잘못 설정, `BuildingCatalog` 미등록 → 로드 시 머스킷으로 복원 | 대공 타워를 지은 세이브를 **로드하는 장면을 찍지 말 것.** 대공 타워는 한 세션 안에서만 노출 |
| 연구 노드 10개 | 효과 비어 있음 (속성 타워 해금, 속성 분기, 관통/범위, 역설계, 외곽 기본자원, 대각선 생산, 자동 생산선, 자동 정산, 일괄 관리, 성 즉시 수리) | 연구 시연은 **효과가 붙은 15개 노드 중에서만** 선택 |
| 봉인석 승리 경로 | 건설·승리는 동작하나 연구 해금 조건 미연결 (항상 해금 상태) | 봉인석 승리를 찍는다면 "연구로 해금된다"는 설명은 하지 말 것. 승리 화면만 보여주거나 아예 생략 |
| 생명 타워 | `master` 기준 미구현 | 속성 타워는 얼음·불·암석·시간 4종만 언급 |
| 몬스터 사망 자원 드랍 | 미구현 | 자원 획득 경로는 "생산시설 정산 + 점령"만 설명 |
| 몬스터 오브젝트 풀링 | 미적용 | 적이 대량으로 몰리는 최대 부하 구간을 길게 잡지 말 것 (프레임 드랍 위험) |
| 튜토리얼 완주 | 1~3일차 전 구간 QA 미완 | 튜토리얼은 **1일차 초반 안내 오버레이만** 짧게. 완주 장면은 찍지 말 것 |

> 위 항목들은 발표 슬라이드 20장(추후 개선점)에 이미 "잔여 공백"으로 정직하게 명시해 뒀습니다.
> 영상에서는 굳이 드러내지 않되, Q&A에서 물으면 그대로 답하면 됩니다.

## 4. 촬영 전 준비 — 세이브 슬롯 사전 제작

전체를 1회차 플레이로 이어 찍으면 8분에 절대 안 들어갑니다. **아래 4개 상태를 미리 세이브로 만들어 두고 구간별로 나눠 촬영**하는 것을 강력히 권장합니다.

| 슬롯 | 상태 | 촬영 구간 |
|---|---|---|
| A | 1~2일차, 건물 거의 없음 | 02 건설·인구 배치, 03 첫 밤 방어, 04 정산 |
| B | 8~12일차, 타워 다수 + 점령 1~2회 완료 + 연구소 가동 | 05 점령, 06 연구 |
| C | 15~21일차, 어미용 스킬 다수 해금 + 새끼용 1~2마리 보유 + 속성 타워 완비 | 07 어미용, 08 새끼용, 09 보스 |
| D | 27일차 밤 직전, 최종 보스 대비 완료 | 09 최종 보스, 10 승리 화면 |

> ⚠️ 세이브 로드 시 대공 타워 예외가 있으므로, **A~D 슬롯에는 대공 타워를 짓지 말 것.**

추가 준비:

- 촬영 전 **UI 언어를 한국어로 고정** (스트링테이블 2개 언어 지원)
- `[미정]` 접두어가 붙은 번역 미확정 문구가 화면에 잡히지 않는지 사전 점검
- 창 모드 대신 **전체화면 1920×1080 고정**, 다른 프로그램 알림 차단
- 마우스 커서 궤적이 산만하지 않도록 클릭 전 잠깐 멈추는 습관

## 5. 편집 · 인코딩 가이드

### 100MB 제한 맞추기

8분 영상을 100MB에 담으려면 **총 비트레이트 약 1.6 Mbps** 이하가 필요합니다.

| 설정 | 권장값 |
|---|---|
| 해상도 | 1920×1080 |
| 프레임레이트 | 30fps (전투 구간 때문에 60fps는 비트레이트를 감당 못 함) |
| 코덱 | H.264 (호환성 최우선) |
| 영상 비트레이트 | **1,400 kbps** (2-pass VBR 권장) |
| 오디오 | AAC 128 kbps, 스테레오 |
| 예상 용량 | 8분 × 1.53 Mbps ≈ **92 MB** |

> 화질이 부족하면 720p(1280×720) + 2,000 kbps 조합도 좋은 선택입니다.
> 타워디펜스는 정보 밀도보다 움직임이 많아, **720p 고비트레이트가 1080p 저비트레이트보다 깔끔하게 보일 수 있습니다.**
> 그래도 안 맞으면 제출 요건상 **별도 파일 분할 제출이 허용**되므로 무리해서 화질을 깎지 말 것.

### 편집 원칙

- **화면 전환마다 자막 타이틀 삽입** — "① 낮 — 건설과 인구 배치" 같은 구간 라벨. 음성이 안 들리는 환경에서도 구조가 보임
- **강조할 수치는 화면에 확대 오버레이** — 남은 인구, 식량 증감, 타워 충원율은 HUD 글자가 작아 그냥은 안 읽힘
- **무음 구간 금지** — 조작만 하고 설명이 없는 구간이 생기면 길게 느껴짐. 대본을 먼저 쓰고 거기에 화면을 맞출 것
- **BGM은 게임 내 사운드보다 확실히 낮게.** 내레이션 > 게임 효과음 > BGM 순서
- 로딩·대기 시간은 전부 컷. 낮 조작은 필요하면 1.5~2배속 후 내레이션만 정상 속도

### 녹화 도구

OBS Studio 권장 설정 — 소스: 게임 캡처(전체화면) / 출력: mp4, CQP 20 정도로 **일단 고화질 원본을 확보**하고,
편집 후 최종 인코딩에서 위 비트레이트로 압축합니다. 녹화 단계에서 미리 압축하면 편집 중 화질이 무너집니다.
