## PR 귀속에 대해

담당 PR 0건은 코드 기여가 없었다는 뜻이 아니다. 이 저장소는 `Merge pull request #N` 형태의
PR 머지 110건 외에도 로컬 브랜치 병합·`git pull` 동기화 머지가 99건 더 있고, 그 경로로 들어간
커밋은 "담당 PR" 집계에 잡히지 않는다. 대신 **머지 수행 92건(전체 PR의 83.6%)**이 이 사람이
다른 팀원의 PR을 리뷰·통합하는 쪽에 서 있었음을 보여준다. 위 "주요 기여"는 그 통합 작업과
무관하게, 본인이 직접 작성한 커밋만 근거로 삼았다.
