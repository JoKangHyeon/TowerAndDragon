## 6. 알려진 공백 / 후속 조치

우선순위 순입니다.

1. **건물 배치가 세이브에 저장되지 않습니다.** 이어하기 시 지어 둔 타워 · 생산시설이 사라지고, 그 여파로 새끼용 `IsInTower`를 복원 시 강제로 `false`로 만듭니다.
   착수 조건: `Building`에 안정적인 PrefabId + `BuildingCatalog`에 id → 프리팹 조회.
2. **봉인석이 본게임 건설 메뉴에 없습니다.** `BuildingCatalog.asset`에 프리팹 4개만 등록돼 있어 **승리 경로 ②를 SampleScene에서 탈 수 없습니다.**
3. **연구 노드 9개가 효과 없이 이름만 있습니다.** 타워 갈래 **T5가 완전히 비어** 있습니다 (밸런싱으로 노드 3개 제거한 부작용).
4. `ISealStoneUnlockQuery` 구현체가 없습니다. null이면 해금으로 접히므로(fail-open) 봉인석이 연구 없이 항상 해금 상태입니다.
5. `Building.IsOpen`(건물 해금), `GridMap.ResearchUnlockQuery`(청크 자원 해금)가 **죽은 코드**입니다. 기획의 "외곽 기초자원 채집 해금" · "속성 타워 해금" 노드가 이걸 기다리고 있습니다.
6. 몬스터 사망 시 자원 드랍이 TODO입니다. 슬라임은 현재 슬라임 농장 생산으로만 얻습니다.
7. 생명 타워 미구현 · 오브젝트 풀링 보류.
8. 밸런스 수치는 조정 중이며, 본작업은 베타 단계입니다.
