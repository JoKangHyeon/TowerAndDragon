# 특수형 적 우선 타겟팅 후속 검토

작성일: 2026-07-21  
상태: 후속 검토 사항 — 현재 특수 행동 구현 범위에는 포함하지 않음

## 목적

향후 일부 타워가 일반 적보다 특수형 적을 우선 공격할 수 있도록 적 분류와 타겟팅 구조를 확장합니다.

## 권장 방향

- Unity Layer는 물리 탐색 용도로 기존 `Enemy` 레이어를 유지합니다.
- 일반·특수·보스 같은 의미상 분류는 `MonsterData`에 별도 데이터로 둡니다.
- `SpecialBehaviorSO[]`는 실제 능력 실행만 담당하며, 특수형 여부를 자동 판정하는 용도로 사용하지 않습니다.
- 타워의 우선순위는 `TowerData`에 타겟팅 정책으로 설정하고, `TowerAttack`이 탐색된 후보를 정렬·선택하도록 합니다.

예상 구조는 다음과 같습니다.

```csharp
[System.Flags]
public enum MonsterTrait
{
    None = 0,
    Special = 1 << 0,
    Boss = 1 << 1
}

public enum TowerTargetPriority
{
    Closest,
    SpecialFirst,
    BossFirst
}
```

## Layer로 분리하지 않는 이유

- 하나의 GameObject에는 하나의 Layer만 지정할 수 있어 복합 분류 확장이 어렵습니다.
- Layer 설정 누락 시 적이 타워의 탐색 대상에서 완전히 빠질 수 있습니다.
- 특수형 우선 공격은 충돌 규칙이 아니라 타겟 선택 정책에 해당합니다.

## 적용 시점

특수형 적과 타워 종류가 실제로 추가되어 우선 공격 요구사항을 검증할 수 있을 때 적용합니다. 현재는 모든 몬스터를 동일한 `Enemy` 탐색 대상으로 유지합니다.
