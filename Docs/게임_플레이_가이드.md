# Tower and Dragons 핵심 플레이 가이드

낮에 방어 시설을 준비하고, 밤에 몰려오는 적으로부터 메인 성을 지키는 게임입니다.

## 목표

- **승리:** 28일차 최종 보스 격파
- **패배:** 메인 성의 체력이 0이 됨
- 보스는 7일, 14일, 21일, 28일차에 등장합니다.

## 조작

| 조작 | 기능 |
|---|---|
| `WASD` / 방향키 | 카메라 이동 |
| 좌클릭 드래그 / 마우스 휠 | 화면 이동 / 확대·축소 |
| 좌클릭 | 선택·배치·확정 |
| 우클릭 / `ESC` | 취소·창 닫기 |
| `R` | 건물 회전 |
| `Space` | 밤 전투 일시정지 |
| `Tab` | 새끼용 인벤토리 |

## 플레이 순서

1. **빌드 모드**에서 공격로 주변에 타워를 건설합니다.
2. 생산시설은 초록색으로 표시되는 자원 지역에 건설합니다.
3. 건물을 클릭해 인구를 배치합니다.
   - 타워는 인구가 없으면 공격하지 않습니다.
   - 생산시설은 인구가 많을수록 생산량이 증가합니다.
4. 필요하면 점령·연구·용 설정을 진행합니다.
5. **밤으로 변경** 버튼을 눌러 웨이브를 시작합니다.
6. 모든 적을 처치하면 다음 날이 자동으로 시작됩니다.

## 핵심 기능

| 기능 | 사용 방법 |
|---|---|
| 인구 | 타워·생산·연구·점령이 하나의 가용 인구를 공유합니다. |
| 생산 | 식량·통나무·돌을 생산하며, 결과는 다음 날 지급됩니다. |
| 점령 | 인접 지역을 선택해 원정을 보냅니다. 완료 시 영토·인구·자원을 얻습니다. |
| 연구 | 연구소에 인구를 배치해 RP를 얻고 연구를 즉시 진행합니다. |
| 용 | 메인 성에서 속성을 낮에 한 번 변경하고, 밤에 해금된 스킬을 사용합니다. |
| 전투 속도 | 밤에 일시정지·재생·2배속·3배속을 사용할 수 있습니다. |

## 처음 플레이할 때

- 보이는 공격로에 타워 2~3개를 먼저 건설합니다.
- 타워에 인구를 우선 배치하고, 남는 인구를 생산시설에 배치합니다.
- 생산시설을 최소 1개 운영합니다 (현재 식량이 소모 되진 않습니다).
- 첫 방어가 안정된 뒤 점령을 시작합니다. 점령할수록 적이 강해지고 많아집니다.

> 현재 프로토타입의 일부 문구·밸런스·연구 및 용 효과는 조정 중입니다.
