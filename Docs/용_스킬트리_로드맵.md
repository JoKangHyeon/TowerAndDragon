# 용 스킬트리 로드맵 (초안)

> 작성일: 2026-07-23 / 기준 문서: `기획종합_v2.md` §10(용), §8(자원), §6(주기)
> **용 스킬트리는 연구 시스템(§14)과 완전히 분리된 별도 시스템·별도 UI 창입니다.**
> 연구소·RP를 사용하지 않습니다. 구체 수치는 예시이며 밸런싱 대상. 기획 `[미정]` 항목은 확정 구현하지 않습니다.

---

## 1. 연구와의 분리 원칙

| 구분 | 연구 (연구소) | 용 스킬트리 (본 문서) |
|---|---|---|
| UI | 연구소 창, 3탭(타워/생산/편의) | **별도 창** (연구소와 무관) |
| 재화 | RP + 기본/특화 자원 | **슬라임 + 특화 자원** (§8·§10), RP 미사용 |
| 진행 | 코스트 즉시 소모 → 즉시 적용 | 코스트 즉시 소모 → 즉시 적용 (대기 없음) |
| 성장 축 | 티어(주기) 게이팅 | **속성 레벨** 게이팅 (속성별 독립) |
| 대상 | 타워·생산·편의 강화 | 어미용 5속성 스킬 + 새끼용 |

두 시스템은 데이터·매니저·UI 모두 독립. 서로의 진행도를 공유하지 않습니다.

---

## 2. 창 구성 — 5속성 서브트리

용 스킬트리 창은 **5속성**(얼음 · 불 · 시간 · 암석 · 생명)을 개별 서브트리로 표시합니다.
어미용은 속성을 **낮에 1회 변경** 가능하며, 속성별 **레벨**이 존재합니다(§10).

- **속성 선택 영역** — 5속성 중 현재 활성 속성 표시/변경.
- **어미용 스킬 라인** — 활성 속성의 패시브·액티브·강화 노드.
- **새끼용 스킬 라인** — 보유한 새끼용(주기당 1마리, §6·§10)의 속성 스킬.

---

## 3. 게이팅 — 속성 레벨 기반

연구의 "주기 티어"와 달리, 용은 **속성 레벨**로 상위 노드를 해금합니다.

| 단계 | 해금 조건(제안) | 내용 |
|---|---|---|
| L1 | 속성 각성 | 패시브 맵 효과 |
| L2 | 속성 레벨 도달 + 선행 완료 | 액티브 스킬 I |
| L3 | 속성 레벨 도달 + 선행 완료 | 수치 강화 / 새끼용 스킬 |
| L4 | 상위 속성 레벨 | 액티브 스킬 II |
| L5 | 최대 속성 레벨 | 속성 궁극 |

> 속성 레벨 상승 조건(어떤 행동으로 오르는지)은 기획 `[미정]`. 슬라임 섭취·해당 속성 사용 등 후보를 팀 확정 필요.

---

## 4. 어미용 노드 (속성별 반복)

각 속성이 동일한 5단 패턴을 따릅니다. 패시브/액티브 효과는 기획 §10 표를 그대로 사용합니다.

| 단계 | 노드 | 선행 | 효과 | 예시 코스트 |
|---|---|---|---|---|
| L1 | 속성 각성 *(루트)* | — | 패시브 맵 효과 해금 (예: 생명=농장 생산량↑) | 슬 소량 |
| L2 | 액티브 스킬 I | 각성 | 속성 액티브 해금 (예: 얼음=모든 적 빙결) | 슬·특화 |
| L3 | 스킬 강화 | 액티브 I | 패시브·액티브 수치 강화 | 슬·특화 |
| L4 | 액티브 스킬 II | 스킬 강화 | 쿨다운↓·범위↑·틱뎀 가속 등 상위 효과 | 슬 다량·특화 |
| L5 | 속성 궁극 | 액티브 II | 속성별 최종 강화 | 슬 다량·특화 다량 |

속성별 액티브(§10): 얼음=모든 적 빙결 / 불=화상 틱뎀 가속·전역 대미지 / 시간=파괴 타워 즉시 수리 / 암석=메테오 / 생명=바리케이드.

---

## 5. 새끼용 노드

새끼용은 **주기 보스 보상 / 용 둥지**에서 주기당 1마리 획득(§6·§10), 슬라임 섭취로 성장.
전투형/버프형 선택과 속성별 효과가 있으며, 일부는 기획 `[미정]`이라 노드도 `[미정]` 처리합니다.

| 속성 | 타워 효과 | 지역 효과 | 비고 |
|---|---|---|---|
| 얼음 | 슬로우 타워 | 주변 강 결빙 → 건물 배치 | — |
| 불 | 화상 타워 | 시야 범위 증가 | — |
| 시간 | `[미정]` | 점령 공격대 포함 가능 | 타워 효과 노드 보류 |
| 암석 | `[미정]` | 주변 광산 생산량↑ | 타워 효과 노드 보류 |
| 생명 | `[미정]` | 주변 농장 생산량↑ | 타워 효과 노드 보류 |

- 전투형/버프형 선택의 상세 규칙 `[미정]` — 노드화 보류.

## 6. 데이터 구조 제안 (구현 관점)

연구와 **분리된 독립 시스템**으로 둡니다(공유 자료구조 없음).

- `DragonSkillNodeData` (SO): 노드 1개 — `NameLocKey`, `Attribute`(enum: 얼음/불/시간/암석/생명), `Level`(1~5), `Prerequisites`(DAG), 코스트(슬라임·특화 자원), 효과(`IDragonSkillEffect`).
- `DragonSkillManager` (매니저): `ResourceManager` 패턴 준수(싱글톤 아님, `GameManager` 주입, `UnityEvent` 통지). 속성별 레벨·완료 노드(`HashSet`) 보유, 효과는 조회(pull) 방식.
- 어미용 속성 변경(낮 1회)·속성 레벨은 이 매니저가 상태로 관리.
- **즉시 적용 모델**이라 진행 타이머·UniTask 대기 불필요.
- CLAUDE.md 리터럴·문자열·네이밍 규칙 준수.
