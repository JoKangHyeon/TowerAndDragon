## 3. 우선순위

### P0 — 제출 차단 항목

#### 3.1 튜토리얼 1~3일차 완주 QA

- 1일차: 건설 기초 → 인구 배치 → 첫 밤 방어
- 2일차: 생산시설 3종 → 새끼용 → 점령 → 연구
- 3일차: 어미용 속성 변경 → 용 스킬트리 → 액티브 스킬 → 보스 → 엔딩
- 필수 목표 미완료 시 밤 진입 차단 및 남은 목표 수 안내 확인
- 자원·인구 하한 보장, 자유 건설 상한 확인
- 안내 오버레이 전환 시 깜빡임·중복·입력 잠금 확인
- `B`·`V`·`C`·`ESC`·휠 안내와 실제 입력 일치
- 한국어·영어 각각 문구 잘림·키 노출 확인
- **완료 후 `튜토리얼_재구성_마일스톤.md` M4~M12 상태를 실제 결과로 갱신**

#### 3.2 본게임 28일 완주 + 봉인 승리

- 최종 보스 격파 경로 1회 완주
- 봉인석 4개 건설 승리 경로 1회 완주
- 7·14·21·28일차 보스, 8·15·22일차 포탈 개방 직후 난이도 기록
- 날짜별 보유 자원·최대/배치 인구·타워 수 기록
- 특수 타워 6종이 실제 전략 선택지로 작동하는지 확인 (화살/석궁 단일 전략 압도 여부)
- 식량·목재·석재·슬라임 병목 시점 기록
- **결과를 `BalanceReport/BalanceNote.md`에 이전값·변경값·이유·재테스트로 기록**

#### 3.3 연구·랜드마크 관문 검증

- 연구 전 특수 타워 10종 건설 잠금 및 잠금 사유 표시
- 연구 후 건설 가능 전환
- 봉인석 해금 노드(`RN_ConvenienceSealStone`) 미연구 시 건설 차단
- 청크 자원 해금(`GridMap.ResearchUnlockQuery`) 전/후 동작
- 랜드마크 수령 → 연구 해금 → 알림 → 건설까지 경로 1회 통과
- 38노드 중 표본 10개의 효과가 실제 수치로 반영되는지 확인
- 연구·해금 상태의 저장/복원

#### 3.4 세이브/로드 통합 회귀

한 슬롯에 아래 상태를 구성한 뒤 저장 → 타이틀 → 이어하기.

- 이동·회전한 기본 타워, 속성 타워, 대공 타워, 특수 타워 6종
- 인구가 배치된 생산시설·연구소, 비활성화된 타워
- 공격/버프 모드 새끼용, 굶음 상태 새끼용
- 진행 중인 점령 원정, 점령 완료 영토, 랜드마크 수령 이력
- 연구·용 스킬트리 해금 상태, 봉인석, 가이드 퀘스트 완료 상태
- 하드모드(뮤테이터) 선택 상태

추가 확인:

- 낮 정산 후 자동 저장에서 생산·유지비 중복 적용 여부
- 1일차 새 게임/재시작 시 이전 자동 저장 잔존 여부
- 구버전 슬롯 로드 시 정규화 또는 명확한 거부

#### 3.5 로컬라이징 `[미정]` 마감

- 신규 키(뮤테이터·랜드마크·특수 타워)의 en/ko 키 정합성 확인
- 한국어 → 영어 → 한국어 전환으로 잔존분 전수 확인

#### 3.6 씬 배선 일괄 점검

- 빌드 설정 포함 씬 전체에 `/run-wiring-checker` 실행
- 미연결 인스펙터 참조 · Missing Script · 끊긴 UnityEvent 리스너 0건
- 특히 반복 유실 이력이 있는 대상 우선 확인
  - `SampleScene.unity` · `Tutorial.unity` · `UI_Canvas.prefab` · `TD_*.asset`
  - 배속(`Speed_settings`), 타워 투사체, `TowerAuraSystem`, `BabyDragonTower`
- **제출 빌드 직전에 한 번 더 실행한다**

### P1 — 제출 품질 항목

#### 3.7 하드모드 · 뉴게임+ 노출 범위 결정

- 베타 계획에 없던 신규 기능이므로 **노출/숨김을 먼저 결정한다**
- 노출 시: 뮤테이터 13종 문구 확정 + 효과 실제 적용 확인 + 저장/복원 확인
- 숨김 시: 시작화면 버튼·건설 메뉴·도감·로컬라이징에서 잘못된 노출 제거

#### 3.8 사운드 마감

- 웨이브 최대 밀집 구간에서 SE 중첩·클리핑 확인
- 낮/밤·보스·승리·패배·UI 사운드 및 이펙트 효과음 누락 확인

#### 3.9 성능 · 안정성

- 웨이브 최대 밀집 구간 프레임 측정 (몬스터 풀링 미적용 상태)
- 프레임 저하가 확인되면 몬스터 풀링을 P1로 승격, 아니면 제출 범위 제외로 확정
- 28일 완주 중 예외 로그 0건 확인

#### 3.10 UI 최종 점검

- 16:9 지원 해상도별 주요 창 겹침·잘림
- `ESC` 닫기 순서와 배타 모드 충돌
- 겹친 건물 선택 순환 및 툴팁 대상 일치
- 적 툴팁·적 도감 수치가 실제 데이터와 일치
- 슬라임 잔량 `▲`·`▼`·`!`와 실제 다음 날 정산 일치
- 1배·2배·3배 및 일시정지 상태에서 UI·사운드 동작
