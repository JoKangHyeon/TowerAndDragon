# TnD 진행현황 보드 — Figma 플러그인

Figma 캔버스에 **Tower and Dragons 프로젝트 진행 현황 보드**(3600 × 4204px, 한 장)를 네이티브 노드로 생성합니다.
발표 시 프레젠테이션 모드 대신 캔버스를 줌인/줌아웃하며 설명하는 용도입니다.

## 실행 방법

Figma **데스크톱 앱**이 필요합니다. (브라우저에서는 로컬 플러그인을 불러올 수 없습니다.)

1. Figma 데스크톱 앱 실행 → 아무 디자인 파일이나 열기 (새 파일 권장)
2. 상단 메뉴 **Plugins → Development → Import plugin from manifest...**
3. `Tools/FigmaProgressBoard/manifest.json` 선택
4. **Plugins → Development → TnD 진행현황 보드** 실행
5. 몇 초 후 보드가 생성되고 자동으로 화면에 맞춰집니다

한 번 등록하면 이후에는 4번만 하면 됩니다. 다시 실행하면 보드가 하나 더 생성되니, 갱신할 때는 기존 보드를 지우고 실행하세요.

## 생성되는 구조

```
▣ TnD 진행현황 보드                 (3600 × 4204, 세로 오토레이아웃)
├─ 헤더                             타이틀 · 컨셉 · 전체 진척도 78%
├─ 핵심 지표                        커밋 587 / 스크립트 232 / 라인 21,580 / 에셋 187 / 프리팹 82 / 씬 8
├─ 마일스톤 타임라인                프로토타입 → 알파 → 베타 → 제출, 오늘(7/29) 마커
├─ 일별 커밋 활동                   21일간 막대 그래프
├─ 상태 범례
├─ 시스템 현황 그리드               시스템 카드 13개 (4 × 3 + 1)
└─ 푸터

🧩 컴포넌트                          보드 왼쪽에 별도 배치
└─ ◆ 시스템 카드                    마스터 컴포넌트 — 수정하면 카드 13개 전부 반영
```

**파일 스타일도 함께 등록됩니다.**

- 컬러 13종: `TnD/배경`, `TnD/패널`, `TnD/포인트-앰버`, `TnD/상태-완료` 등
- 텍스트 6종: `TnD/디스플레이`, `TnD/섹션 제목`, `TnD/카드 제목`, `TnD/수치`, `TnD/본문`, `TnD/캡션`

전체 톤을 바꾸려면 스타일 값만 수정하면 됩니다.

## 데이터 수정

`code.js` 최상단 **"0. 데이터"** 블록만 고치면 됩니다. 그 아래는 렌더링 로직입니다.

| 상수 | 내용 |
| --- | --- |
| `META` | 프로젝트명, 타이틀, 컨셉, 기준일, 팀 |
| `KPIS` | 상단 핵심 지표 6개 |
| `TIMELINE` | 마일스톤 시작/종료/오늘 날짜, 구간, 마커 |
| `COMMITS` | 일별 커밋 수 `['7/13', 89]` 형식 |
| `SYSTEMS` | 시스템 카드 — `pct`(완성도), `status`(`done`/`partial`/`weak`), `desc`, `meta` |

전체 진척도(78%)는 `SYSTEMS`의 `pct` 평균으로 자동 계산됩니다.

커밋 수를 갱신하려면 저장소 루트에서:

```bash
git log --pretty=format:"%ad" --date=short | sort | uniq -c
```
